1. Context & Goals

Purpose

Forecast NYC taxi demand at the (pickup zone, hour) grain for short-horizon windows (h+3 h+6 h+12), exposed via a FastAPI HTTP endpoint and (later) a React heatmap UI.

Portfolio Goals

  • Demonstrate a clean medallion architecture (Bronze → Silver → Gold).
  • Showcase MLflow experiment tracking and DVC data versioning.
  • Provide a working FastAPI prediction service with production-quality code (strict typing, tests, lint/format).
  • Lay groundwork for a frontend visualization layer.

Non-Goals

  • Production-grade scale (single-node, local-first).
  • Multi-tenant auth (no user accounts, no rate limiting).
  • Real-time streaming (batch hourly cadence is sufficient).

Constraints

ConstraintValue
ComputeSingle-node, optional CUDA 12.6
StorageLocal filesystem, parquet-based
RuntimePython 3.13+, uv-managed
Latency target (serving)< 200ms p95 for /predict
Training cadenceManual / nightly cron
Data volume~10–100M trip rows/year, downsampled per slice

3. Component Responsibilities

Configuration shared

src/shared/config.py — single source of YAML config loading via load_config(). config.yml owns: data paths, train/test split, model hyperparameters, MLflow experiment name.

Ingestion Bronze→Silver

ingest.py downloads from Socrata to Bronze parquet. clean.py drops nulls, removes non-positive trips, clips fare outliers via IQR, engineers hour / day_of_week / month / is_weekend.

Feature Engineering Silver→Gold

Aggregates Silver trips to (pickup_zone, datetime_hour); adds lag (h-1, h-24, h-168), rolling means, calendar features. Output partitioned by month with target trip_count.

Training trainer

Trainer loads Gold, performs time-based split only, splits X/y via feature_target_separator(), fits LGBMRegressor, saves to models/model.pkl, and logs to MLflow under ny_taxi_demand_model.

Inference offline

Predictor loads models/model.pkl and computes MAE / RMSE / R² on held-out time slices. Used by batch eval scripts, not by the live API.

Serving FastAPI

src/serving/app.py exposes POST /predict. Loads models/model.pkl at startup. Root app.py re-exports the app so uvicorn app:app works.

Frontend planned

Vite + React + TypeScript SPA at frontend/, using @tanstack/react-query. Vite dev server proxies /api → http://127.0.0.1:8000. Primary view: zone × hour heatmap.

Monitoring planned

Evidently for drift reports against a frozen reference dataset; scheduled offline. /health and /model-info endpoints to follow.

4. Data Flow & Interfaces

4.1 Ingestion Flow (per month)

Socrata API ──► raw trips JSON
            ──► data/bronze/yyyy=YYYY/mm=MM/trips.parquet  (raw schema)
            ──► clean.py
            ──► data/silver/yyyy=YYYY/mm=MM/trips.parquet  (cleaned + time features)

4.2 Feature Engineering Flow

data/silver/**.parquet
   ──► groupby(pickup_zone, hour_bucket)
   ──► aggregate trip_count
   ──► join lag/rolling/calendar features
   ──► data/gold/yyyy=YYYY/mm=MM/features.parquet
       schema: [pickup_zone, datetime_hour, hour, day_of_week, month,
                is_weekend, lag_1h, lag_24h, lag_168h, roll_24h_mean, ...,
                trip_count]

4.3 Training Flow

data/gold/**.parquet
   ──► time-split (last N% by datetime_hour as test)
   ──► X_train, y_train, X_test, y_test
   ──► LGBMRegressor.fit(X_train, y_train)
   ──► MLflow.log_params + log_metrics + log_artifact(model.pkl)
   ──► models/model.pkl

4.4 Serving Interface — POST /predict

Request

{
  "pickup_zone": 132,
  "datetime_hour": "2026-05-18T14:00:00Z",
  "horizons": ["h+3", "h+6", "h+12"]
}

Response

{
  "pickup_zone": 132,
  "base_time": "2026-05-18T14:00:00Z",
  "predictions": [
    {"horizon": "h+3",  "target_time": "2026-05-18T17:00:00Z", "trip_count": 42.7},
    {"horizon": "h+6",  "target_time": "2026-05-18T20:00:00Z", "trip_count": 58.1},
    {"horizon": "h+12", "target_time": "2026-05-19T02:00:00Z", "trip_count": 18.3}
  ],
  "model_version": "ny_taxi_demand_model@1"
}

Errors

StatusCause
400Invalid zone id, malformed datetime, unsupported horizon
404No feature row available for the requested base time
503Model not loaded at startup

5. Key Design Decisions

DecisionRationale
Medallion architectureClear layering: Bronze = raw audit trail, Silver = clean, Gold = ML-ready.
Parquet on local FSSimple, columnar, zero-infra. Good fit for portfolio scope.
DVC for data versioningReproducible pipelines without a data warehouse.
LGBMRegressor firstStrong tabular baseline; deep models can be added later behind the MODELS dict.
Time-based split onlyAvoids leakage on temporal data. Hard rule (pipeline.MD §6).
MLflow local storeNo tracking-server infra needed; mlruns/ is git-ignored.
Model loaded at FastAPI startupPredictable cold-start cost paid once; sub-200ms p95 inference.
app.py re-export shimLets uvicorn app:app work from repo root without PYTHONPATH tricks.
config.yml over env for ML knobsHyperparameters and paths belong in versioned config; .env is only for secrets.

6. Cross-Cutting Concerns

Configuration

  • All ML/data knobs live in config.yml, loaded once via src.shared.config.load_config().
  • Secrets (Socrata app token, DB creds) live in .env, never committed.

Logging

  • Structured logs to stdout via Python's logging with module-level loggers.
  • Log level controlled via env var; default INFO.

Error Handling

  • Boundary validation: Pydantic models on FastAPI request schema.
  • Internal exceptions wrapped at the API layer into 4xx/5xx — never leak stack traces.
  • Trainer/predictor raise specific exceptions; no bare except.

Testing

  • tests/ mirrors src/.
  • Unit tests for clean, feature engineering, trainer, predictor.
  • Integration test: smoke-test /predict against a fixture model.
  • All tests run via uv run pytest; CI enforces strict mypy + ruff.

Observability

  • MLflow for model lineage (params/metrics/artifacts).
  • Evidently (planned) for drift monitoring against a reference dataset.
  • /health endpoint (planned) for liveness/readiness.

Security & Hygiene

  • No secrets in code or config.yml.
  • .parquet / .csv under data/ are gitignored.
  • CORS configured restrictively for the planned frontend dev origin only.
